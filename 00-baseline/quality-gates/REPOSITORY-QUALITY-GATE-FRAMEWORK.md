## Gates

GATE-01 Metadata, GATE-02 Identity, GATE-03 Cross-Reference, GATE-04 Dependency, GATE-05 Authority, GATE-06 Traceability, GATE-07 Release, GATE-08 Evidence, GATE-09 Certification, and GATE-10 Repository Audit.

Every gate defines entry/exit criteria, evaluated controls, validation standards, evidence, and one outcome: PASS, PASS WITH CONDITIONS, FAIL, or WAIVED. Independent gates may execute concurrently after prerequisites pass. Evidence uses the Repository Validation Execution Context (RVEC).
