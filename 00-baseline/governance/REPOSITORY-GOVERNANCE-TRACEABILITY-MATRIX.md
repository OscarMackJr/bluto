The RGTM is the single governance graph connecting Constitutional Principles (CP), Repository Control Objectives (RCO), Repository Controls (RC), Quality Gates (GATE), Validation Standards (VAL), Review Evidence (REV), Certifications (CERT), Releases (REL), and implementation. Every governed artifact has upstream and downstream traceability; orphaned controls or alternate governance paths are prohibited. The machine-readable projection is generated under `/repository/rgtm`.

## Document control

This controlled document is immutable in this release. Changes require the approved ADR and change-control process. Cross-references use Constitutional Document IDs; filenames are non-authoritative.
