Documents use MAJOR.MINOR.PATCH governance semantic versioning. Patch is editorial with no semantic change; minor is backward-compatible clarification or additive guidance; major changes normative meaning or authority and requires ADR, impact analysis, and recertification. Published versions are immutable and compatibility is assessed independently from version numbering.

## Document control

This controlled document is immutable in this release. Changes require the approved ADR and change-control process. Cross-references use Constitutional Document IDs; filenames are non-authoritative.
