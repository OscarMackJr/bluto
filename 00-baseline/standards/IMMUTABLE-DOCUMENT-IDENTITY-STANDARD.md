Each logical controlled document has one permanent Constitutional Document ID. Each published version has one Artifact ID. Each certified package has one Release ID. IDs are never reused. The grammar is `BLUTO-<scope>-<category>-<sequence>`, `ART-<document-id>-v<version>`, and `REL-<scope>-<version>`. The Logical Identity Registry is the machine-readable source for allocation state and lineage.

## Document control

This controlled document is immutable in this release. Changes require the approved ADR and change-control process. Cross-references use Constitutional Document IDs; filenames are non-authoritative.
