The canonical logical metadata categories are Identity, Governance, Lineage, Lifecycle, Traceability, and Publication. Mandatory fields are Document ID, Artifact ID, title, version, status, owner, baseline, stream, authority level, dependencies, supersession, approval/effective/review dates, and classification. Serialization is technology-neutral; the generated registry uses YAML and JSON while documents use human-readable tables.

## Document control

This controlled document is immutable in this release. Changes require the approved ADR and change-control process. Cross-references use Constitutional Document IDs; filenames are non-authoritative.
