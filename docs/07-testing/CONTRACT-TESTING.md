## Governing rules

This document derives from upstream baselines and does not redefine domain ownership, architecture topology, security posture, or historical semantics. Identity is deterministic and batch-resolved for v1; tenant scope is explicit; raw strong identifiers are never persisted; Party identifiers are immutable; hometown is a read-only consumer.

Provider tests validate every OpenAPI/JSON/event schema example and error outcome. Consumer tests cover active hometown and stewardship expectations. Compatibility tests compare candidate schemas with all supported prior versions.

Event tests prove required envelope fields, no prohibited data, duplicate safety, out-of-order tolerance, and parallel major-version operation.
