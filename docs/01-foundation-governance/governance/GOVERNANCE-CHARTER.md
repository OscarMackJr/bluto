Enterprise Architecture is accountable for architectural coherence. Domain Architecture owns business semantics; Security owns control adequacy; Engineering owns implementation conformance; Data Stewardship owns review operations; Product owns priority and acceptance; Release Management owns certified publication. Codex is an implementation consumer without approval authority.

Decisions are made at the lowest authorized layer that does not affect upstream authority. Cross-stream conflicts escalate to Enterprise Architecture and, when constitutional, to the Architecture Review Board.
