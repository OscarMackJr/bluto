Canonical terms include Party, Party Identifier, Source Record, Source System, Source Key, Party Source Link, Identity Resolution, Candidate, Match Rule, Rule Version, Deterministic Match, Review Case, Review Decision, Merge, Split, Retirement, Identity Lineage, Effective Date Range, Tenant, Correlation ID, and Causation ID.

Forbidden internal synonyms include Golden Record, Master Customer, Best Record, Duplicate Customer, and fuzzy match for v1. External terms such as CRM Contact, Borrower, and Ledger Customer are translated at adapters and never redefine the core language. Generated code, contracts, schemas, tests, and documentation use this vocabulary.
